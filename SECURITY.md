# Security policy

Event Flow is under active development and is not ready to process real
payments or customer data.

Please do not report suspected vulnerabilities in public issues or pull
requests. Enable GitHub private vulnerability reporting for this repository
before inviting external contributions. Until then, contact the maintainers
through a private channel and do not include exploit details in public
discussions.

Do not test against systems, accounts, or data you do not own or have explicit
permission to assess.
